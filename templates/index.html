About UrbanTwin AI

This MCA project prototype simulates a small road network with synthetic vehicles, configurable traffic demand, fixed-time and adaptive signal strategies, emergency priority, performance metrics, and an optional LLM assistant.

Important: It is not connected to real traffic infrastructure. The adaptive policy is rule-based, not a trained reinforcement-learning model. Add an API key only if you want model-powered chat.
